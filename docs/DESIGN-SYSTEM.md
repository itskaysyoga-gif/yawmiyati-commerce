# Design system (draft)

- Logo: `brand/logo.svg` (ink #1F1D1E), `brand/logo-white.svg`, `brand/logo-currentcolor.svg`. Never redraw or recolour beyond these.
- Identity: Kite Creative, monochrome. Latin brand font on stationery: Vista Slab (paid; web use only with a licence).
- Palette: ink #1F1D1E on warm ivory #FAF6EF; one restrained rose accent (to be set in the flagship page); greys for quiet text.
- Arabic UI typeface: one free family chosen with the flagship page.
- Mobile first: 360, 390, 430 px. Sticky order button. RTL everywhere.
