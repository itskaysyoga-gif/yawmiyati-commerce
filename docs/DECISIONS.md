# Decisions

Newest first. Each entry: date, decision, why.

- 2026-10-29 (growth round) — ChatGPT's unified completion and growth brief (29 Oct) adopted as scope, with corrections listed in docs/reports/2026-10-29-completion-growth.md. The rule "no new features unless a launch blocker needs one" is widened to what that brief lists (Rashid, 29 Oct).
- 2026-10-29 — Consent invariant across stores: a withdrawal is queued in the store's own table first (atomic upsert), each store certifies its queue to the shared ledger every 5 minutes, and server ad events are two-phase in every store (decide, wait until every store in YM_CONSENT_STORES certified past the decision, re-read the ledger, send). A store that cannot write the ledger can never certify, so its withdrawals hold everyone's events instead of leaking. Residual window stated in MEASUREMENT.md §4.
- 2026-10-29 — Consent has three states: all (granted), analytics only, essentials only. Advertising server events need "all"; withdrawing advertising counts as a withdrawal across stores.
- 2026-10-29 — Card images are derivatives (YM_Media): cut-outs trimmed to one optical scale, photos never stretched, weak wide photos flagged for another source instead of an enlarged crop. Media records gain channels, editing rights, expiry and owner approval.
- 2026-10-29 — Home focal image: a licensed lifestyle photograph when one exists (ym_hero_image), otherwise the first featured product shown whole. Never three thumbnails, never a generated scene.
- 2026-10-29 — Seed prices follow research/selection/first_wave.csv (one source; Egypt rack 689 is labelled a proposal). Previews and review screenshots carry commit, data revision and time with a PREVIEW ONLY notice.
- 2026-10-29 — Recommendations v1 are curated and deterministic (YM_Reco); never items in the cart, bundle parts, out-of-stock items, or items the page itself sells cheaper as a bundle. No "frequently bought together" claim without data.
- 2026-10-29 — Email: shared permission records in the shared database, double opt-in, strongest-wins suppression across stores, caps 1/day and 3/week, Brevo through a narrow API adapter (not its WooCommerce plugin), all flows off until provider-tested. Abandoned-checkout email not built. WooCommerce's own customer emails off (wrong COD wording). The checkout's email field appears only while receipts are actually sent.
- 2026-10-29 — Content Studio is a separate cloud pipeline (studio/): facts export → Anthropic API brief in CI with a 40 USD cap → rules check (no numbers or banned claims from the model) → Remotion photo-motion renders → QA → owner batch approval → publisher on Meta's Graph API with preflight, reconciliation, pause and dead letter. Postiz, Manychat and narration not used at launch (reasons in docs/CONTENT-STUDIO.md).
- 2026-10-29 — Kill-gates decide on contribution per submitted order with an 80 % band (YM_Gates), replacing "pause below 35 % kept". Break-even CPA is a ceiling, never a bid.
- 2026-10-28 (late) — Submission claims use a conditional INSERT plus a database lock held by the claiming request, not add_option() (an upsert: two simultaneous requests both "won", CI run 40748106500) and not a 30-second expiry (a slow first request lost its claim). The token is written into the order in the same save.
- 2026-10-28 (late) — Order lookups by meta go through one storage-aware helper (YM_Orders::ids_by_meta). wc_get_orders() silently ignores meta_key on classic order storage, which made withdrawal, crash recovery and second-phone matching hit unrelated orders.
- 2026-10-28 (late) — Reporting is built from an append-only order history (YM_Lifecycle): orders counted once, order-level charges once with line-value allocation, funnel by stages reached, refusal / cancellation / return / partial and full refund kept apart, mature cohorts only, unknown costs reported as unknown. A WooCommerce status is evidence only after the supplier's status sync is verified.
- 2026-10-28 (late) — Five countries share one config (config/countries.php) and one release. Four gates per market (prepared, catalog, checkout, ads) in config/markets.json, changed only by commit; a store may switch a gate off locally, never on. All five are "prepared"; none takes orders yet.
- 2026-10-28 (late) — Oman stays prepared but is not opened, and the UAE gets at most a single test product: the supplier catalog there is thin (OM 58 in-scope items, nearly all under 50 units, 3-5 OMR margins; AE 34). Saudi offers wait for the Saudi refusal/return charge. Egypt and Iraq first.
- 2026-10-28 (late) — Shortlists stop at about 40 per country where the catalog supports it (EG, IQ, SA), fewer elsewhere; no padding. Nothing is approved without Rashid. AI ranks with written rules; it never invents demand, delivery rates, competitor prices or stock.
- 2026-10-28 (late) — COD controls: refuse only a honeypot, a browser burst or an extreme connection rate; everything else holds for a person with a reason code. A busy shared IP holds instead of refusing (carriers share IPs). Risk records come only from verified customer-caused refusals, expire, keep history and can be cleared. Holds stay on WooCommerce's normal path (setting on-hold before the first save makes WooCommerce complete the order).
- 2026-10-28 (late) — Measurement: purchase marked only when the browser confirms GTM had loaded; withdrawal stops tags (reload), deletes measurement cookies and cancels queued server events; click IDs before a choice stay in the tab until a yes; the order key leaves the address bar before tags load; OrderDelivered only from a verified delivery, with its own time; retries resend the identical event. WooCommerce's own order attribution is off (it set cookies before consent).
- 2026-10-28 (late) — Media gate checks coverage (clean whole product, detail, scale; demonstration advised), exact SKU, source, rights and original, not a count of 3 or 5. Generated video is never a demonstration.
- 2026-10-28 (late) — Reviews only from verified deliveries via a signed link, all moderated, shown as "bought and received"; rating markup from 3 approved reviews. No admin path to write a review.
- 2026-10-28 (late) — Shop, product and content pages load no WooCommerce CSS, no jQuery and no emoji script; fonts limited to two weights. Lab LCP on a throttled phone fell from 2.5-3.7 s to 0.9-2.0 s. Production speed is measured on the real host and in the field, not here.
