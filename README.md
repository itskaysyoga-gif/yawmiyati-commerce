# yawmiyati-commerce

Arabic, mobile-first cash-on-delivery stores for Yawmiyati (يومياتي), supplied by Taager.
One WordPress + WooCommerce install per country (`/eg/`, `/iq/` at launch), all running the
theme and plugin in this repo.

| Folder | What lives there |
| --- | --- |
| `theme/` | Custom block theme `yawmiyati` |
| `plugin/` | Business plugin `yawmiyati-commerce`: COD form, bundles, order states, tracking |
| `studio/` | Remotion content studio: reels, stories, carousels, ad cuts |
| `research/` | Product Desk: catalog data, matching, scoring, pricing scripts |
| `dev/` | Local WordPress environment for building and testing |
| `brand/` | Logo files and the original Kite Creative stationery |
| `docs/` | Project state, decisions, rules and checklists |

Start with `docs/PROJECT-STATE.md`. The full launch brief lives in the Yawmiyati Claude Project.
